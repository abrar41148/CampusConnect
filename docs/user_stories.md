# User Stories (High‑Level)

## As a **Student**
- I want to **register** and **log in** so I can access my dashboard.
- I want to **view a list of my classrooms** and **join** new ones.
- I want to **see upcoming assignments** and **submit work** before deadlines.
- I want to **receive announcements** from my teachers.

## As a **Teacher**
- I want to **create and manage classrooms** and assign students.
- I want to **post announcements** that appear for all enrolled students.
- I want to **create, edit, and publish assignments** with due dates.
- I want to **review student submissions** and provide feedback.

## As an **Admin**
- I want to **manage user accounts** and assign roles.
- I want to **monitor system health** and view usage metrics.
- I want to **configure system settings** such as email service and security policies.

*All stories follow the INVEST criteria and serve as the basis for sprint backlog items.*
